# gakuchika-log

大学生活の経験を記録し、
就活で困らないための記録アプリ。

## Tech Stack

- React Native
- Expo
- TypeScript

## Concept

大学生活の経験を積み重ね、
未来のガクチカにつなげる。

日々の活動や経験を記録・整理し、
いざESを書くときに「何を頑張ったか」「何に苦労したか」
を思い出せる状態をつくる。

活動は「カテゴリ → プロジェクト → 活動記録」の構造で整理し、
複数の活動記録をもとに、自分自身でガクチカをまとめられるようにする。

AIに文章を作ってもらうのではなく、
自分の経験を記録し、自分の言葉で整理・言語化することを重視する。

## MVP

- 活動記録
- タグ
- カレンダー
- カテゴリ・プロジェクトによる活動整理
- ガクチカ整理
- ES作成

## Future

- ユーザー自身の記録を活用したAI検索・整理支援
- 過去の経験の発掘・関連付け
- AIによる深掘り・振り返り支援
