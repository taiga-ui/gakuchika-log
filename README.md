# gakuchika-log

大学生活の経験を記録し、
就活で困らないための記録アプリ。

## Tech Stack

- React Native
- Expo
- TypeScript

## Concept

大学生活の経験を積み重ね、
未来のガクチカにつなげる。

日々の活動や経験を記録・整理し、
いざESを書くときに「何を頑張ったか」「何に苦労したか」
を思い出せる状態をつくる。

## MVP

- 活動記録
- タグ
- カレンダー
- 写真・成果物の記録
- ガクチカ整理
- ES作成

## Future

- 過去の活動を探しやすくするキーワード検索
- ユーザー自身の記録を活用したAI検索・整理支援
- RAGを活用した過去の経験の発掘・関連付け
- AIによる深掘り・振り返り支援
